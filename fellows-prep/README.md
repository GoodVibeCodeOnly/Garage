# fellows-prep

Preparation material for a possible application to the Anthropic Fellows Program (The Anthropic Institute, Economics & Policy track). It's for reading, keeping or throwing away. Nothing here has been sent anywhere, and whether or when to apply is undecided.

| File | What it is |
|---|---|
| `01_program_brief.md` | What the program and the Economics & Policy track ask for, timing (including the January 2027 question), past fellows' output. Sourced; ⚠ marks unverified items. |
| `02_ten_questions.md` | Ten research questions answerable with public data and small budgets. |
| `03_proposals.md` | One-page proposals for the best three. |
| `04_first_pass_writeup.md` | Honest write-up of a first-pass analysis on the best question. |
| `analysis/` | Python code (`wage_gradient.py`, `observed_vs_predicted.py`) and outputs (`out/`). |
| `05_gaps.md` | Gaps between the applicant and the bar, plainly. |

**Main caveats:**
- The primary Anthropic and Greenhouse pages couldn't be loaded from the build sandbox, so program facts come from search snippets and job-board mirrors.
- Analysis data came from public GitHub mirrors (the Yale Budget Lab repo, the GPTs-are-GPTs repo), not from Hugging Face or BLS directly.
- Re-verify both before relying on anything.
