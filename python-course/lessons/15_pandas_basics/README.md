# 15 — pandas basics

pandas is a spreadsheet you drive with code: a **DataFrame** is a table of named columns, each column a NumPy array underneath. Everything from lesson 14 — vectorised maths, boolean masks — carries over, now with labels. This is the tool you'll use most in a research job.

## Loading and first look

```python
import pandas as pd

df = pd.read_csv("data/matches.csv", dtype={"patch": str})
df.head()        # first 5 rows
df.shape         # (2000, 8)
df.info()        # columns, dtypes, missing values
df.describe()    # count/mean/std/quartiles of numeric columns
```

Always do these four on a new dataset before you analyse anything. `info()` is where you catch type problems — like `patch`. Left alone, pandas reads `1.2, 1.3, 1.4` as floats, so `"1.10"` would become `1.1` and collide with patch 1.1. Labels that look like numbers (patch versions, ZIP codes, IDs with leading zeros) should be read as text with `dtype=`.

## Selecting

```python
df["faction"]                       # one column -> Series
df[["player", "faction", "won"]]    # list of columns -> DataFrame
df["duration_min"].mean()
```

## .loc and .iloc

```python
df.loc[5, "player"]           # by LABEL: index label 5, column "player"
df.loc[df["won"], "faction"]  # labels can be a boolean mask
df.iloc[0]                    # by POSITION: first row
df.iloc[:10, :3]              # first 10 rows, first 3 columns
```

Freshly loaded, label 0 and position 0 are the same row. After sorting or filtering they're not — the index labels travel with the rows. `.loc` = labels, `.iloc` = integer position. Mixing them up is a top-3 pandas bug.

## Boolean filtering

Exactly like NumPy masks:

```python
mongols = df[df["faction"] == "Mongols"]
mask = (df["faction"] == "Byzantium") & (df["map"] == "Bosphorus")
df[mask]["won"].mean()
df[df["map"].isin(["Steppe", "Anatolia"])]
df[~mask]                    # everything else
```

Parentheses around each condition are mandatory (`&` binds tighter than `==`). Use `&`, `|`, `~`, never `and`/`or`/`not`.

## New columns

```python
df["minutes_over_30"] = df["duration_min"] - 30           # vectorised
df["result"] = np.where(df["won"], "W", "L")              # if/else
df["length"] = pd.cut(df["duration_min"], [0, 20, 40, 1000],
                      labels=["short", "medium", "long"], right=False)
```

If you're writing a function that adds columns, `df = df.copy()` first: modifying the caller's DataFrame behind their back is rude and causes confusing bugs.

## Sorting and counting

```python
df.sort_values("duration_min", ascending=False).head(10)
df.sort_values(["faction", "duration_min"])
df["map"].value_counts()                  # counts per category, largest first
df["map"].value_counts(normalize=True)    # shares
```

`value_counts` returns a Series indexed by category. Dividing two such Series **aligns on the index**: `wins_per_faction / games_per_faction` matches Venice with Venice even if the order differs. That alignment is pandas' superpower (and occasionally a surprise — mismatched labels give `NaN`).

## Worked example

`example.py` explores the dataset (generated by `make_data.py` with deliberate balance problems):

1. `head()`, `info()`, `describe()` — get your bearings.
